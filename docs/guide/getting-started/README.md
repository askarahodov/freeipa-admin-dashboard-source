# Начало работы с Admin Dashboard Softrust

## Для кого

Для нового пользователя портала независимо от того, назначена ему роль `viewer`, `operator` или `admin`.

## Что вы сможете сделать

Понять назначение портала, войти, определить свою роль, найти основные разделы и отличить проблему самого портала от недоступности внешней системы FreeIPA или XYOps.

## Что такое портал

**Admin Dashboard Softrust** — административный портал, который объединяет работу с несколькими областями:

- пользователями и группами FreeIPA;
- каталогом и выполнением процессов XYOps;
- операциями, approvals и результатами;
- локальными учётными записями, настройками, диагностикой и эксплуатационными функциями — если у вашей роли есть соответствующие права.

Портал имеет собственные локальные учётные записи и сессии. Пользователь портала и пользователь FreeIPA — это разные сущности.

Подробнее: [`../concepts/TERMINOLOGY.md`](../concepts/TERMINOLOGY.md).

## Вход

1. Откройте адрес портала, который предоставил ваш администратор или служба эксплуатации.
2. На странице входа введите имя локальной учётной записи портала и пароль.
3. После успешного входа портал создаёт локальную сессию. Не копируйте и не передавайте session cookie другим людям.
4. Если вход не удаётся, не пытайтесь обходить проверку через технические токены или внутренние API. Обратитесь к администратору портала.

## Роли простыми словами

### Viewer

Пользователь с правами просмотра. Текущий базовый контракт даёт permission `directory.read`: просмотр FreeIPA users/groups, каталога процессов, операций и результатов, доступных вашей сессии.

### Operator

Оператор дополнительно может выполнять обычные разрешённые изменения FreeIPA и запускать XYOps processes. Конкретная операция всё равно проверяется сервером.

### Administrator

Администратор портала имеет полный набор встроенных portal permissions и доступ к административным разделам. Это не означает, что его локальная учётная запись автоматически является FreeIPA administrator.

Каноническое описание ролей: [`../../reference/PERMISSIONS.md`](../../reference/PERMISSIONS.md).

## Основные области

Названия и расположение элементов интерфейса могут меняться, поэтому ориентируйтесь прежде всего на назначение раздела:

- **Directory / Users / Groups** — просмотр объектов FreeIPA;
- **Automation / Catalog** — каталог процессов XYOps;
- **Operations / Runs** — запуски, состояния и результаты;
- **Approvals** — запросы согласования, доступные текущей роли;
- **Settings / Access / Sessions / Diagnostics** — административные области, доступность которых зависит от роли.

Если раздел не виден, это не доказывает отсутствие API и не означает ошибку. Права всегда проверяются сервером.

## Как понимать состояния

### Нет данных

Запрос выполнился, но подходящих объектов или записей нет. Попробуйте очистить фильтры или изменить условия поиска.

### Нет прав / Forbidden

Ваша текущая роль не разрешает действие или просмотр административной информации. Не пытайтесь обходить это через прямой API-запрос — сервер применяет тот же permission contract.

### Недоступно / Unavailable

Портал не может сейчас получить требуемые данные или выполнить операцию. Причиной может быть зависимость, конфигурация или временный сбой.

### Degraded

Одна из внешних зависимостей работает с ограничениями или недоступна. Это не обязательно означает, что сам портал остановлен: локальные функции могут продолжать работать.

## Если что-то пошло не так

Перед обращением за помощью полезно записать:

- примерное время события;
- какую задачу вы выполняли;
- какой раздел был открыт;
- безопасный error code или correlation ID, если портал их показывает.

Не отправляйте в чат, тикет или письмо:

- пароль;
- session cookie;
- API key;
- `ADMIN_TOKEN`;
- encryption key;
- содержимое локальной базы данных;
- raw upstream response, если поддержка отдельно не дала безопасную процедуру.
