# Массовые операции с пользователями FreeIPA

## Назначение

Раздел `/users` поддерживает массовое включение и отключение пользователей, добавление выбранных пользователей в существующую группу и экспорт отфильтрованного каталога в CSV.

Локальные пользователи портала и пользователи FreeIPA остаются разными сущностями. Массовые операции изменяют только каталог FreeIPA.

## RBAC

- `viewer` видит каталог и может экспортировать CSV;
- `operator` и `admin` могут выполнять массовые изменения;
- сервер повторно проверяет permission `freeipa.write` до запуска мутаций;
- скрытие кнопок в браузере не используется как механизм авторизации.

## Массовый endpoint

```http
POST /api/integrations/freeipa/bulk
Content-Type: application/json
```

Поддерживаемые действия:

```json
{
  "action": "enable",
  "users": ["alice", "bob"]
}
```

```json
{
  "action": "disable",
  "users": ["alice", "bob"]
}
```

```json
{
  "action": "add_to_group",
  "group": "devops",
  "users": ["alice", "bob"]
}
```

Ограничения:

- не более 50 уникальных пользователей за один запрос;
- логины и название группы проходят строгую серверную валидацию;
- операции выполняются с ограниченной параллельностью;
- каждое изменение проходит через существующий `/api/integrations/freeipa/actions`;
- для каждого пользователя сохраняются существующие operation run и audit event.

При полном успехе endpoint возвращает HTTP `200`. При частичном выполнении возвращается HTTP `207` и результат по каждому логину:

```json
{
  "ok": false,
  "action": "add_to_group",
  "group": "devops",
  "requested": 2,
  "succeeded": 1,
  "failed": 1,
  "results": [
    { "uid": "alice", "ok": true, "status": 200, "runId": "...", "error": "" },
    { "uid": "bob", "ok": false, "status": 502, "runId": "...", "error": "already a member" }
  ]
}
```

Повторять следует только строки с `ok=false`. Успешные пользователи автоматически снимаются с выделения в интерфейсе.

## Экспорт CSV

```http
GET /api/integrations/users/export.csv?q=&status=active&group=devops&sort=uid&direction=asc
```

Экспорт применяет те же серверные фильтры и сортировку, что и таблица `/users`, но включает весь подходящий набор, а не только текущую страницу.

Файл:

- кодируется в UTF-8 с BOM;
- использует `;` как разделитель;
- содержит логин, имя, email, статус, количество групп и список групп;
- очищает переносы строк и управляющие символы;
- защищает значения, начинающиеся с `=`, `+`, `-` или `@`, от формульной интерпретации табличными редакторами;
- не содержит FreeIPA credentials, portal cookies или service account password.

## Ограничение реализации

FreeIPA RPC в текущей архитектуре создаёт отдельную серверную сессию для каждой одиночной операции. Bulk-wrapper ограничивает параллельность и размер запроса, но не превращает несколько изменений в атомарную транзакцию. Частичный результат является штатным состоянием и явно возвращается браузеру.
