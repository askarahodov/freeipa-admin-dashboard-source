# Playwright E2E: локальный вход и выход

Сценарий запускает полностью отдельный Dashboard с чистой локальной базой и проверяет пользовательский путь в Chromium.

## Покрытие

- неаутентифицированный переход на `/` перенаправляется на `/login`;
- форма входа доступна и принимает данные;
- неверный пароль показывает серверную ошибку и не создаёт сессию;
- корректный пароль открывает Dashboard;
- панель локального пользователя показывает имя и роль администратора;
- кнопка «Выйти» завершает сессию;
- повторный переход на `/` после выхода снова перенаправляет на `/login`.

## Изоляция

Контур использует:

- `compose.e2e.yaml`;
- отдельный volume `dashboard-e2e-data`;
- профиль `.env.e2e`;
- `DEMO_MODE=true`;
- пустые настройки FreeIPA и XYOps;
- отдельный Docker-образ Playwright с Chromium.

Тест не подключается к рабочим FreeIPA, XYOps и базе основного портала.

## Локальный запуск

```bash
cp .env.e2e.example .env.e2e
npm run test:e2e:auth
```

Файл `.env.e2e` исключён из Git. Значения в `.env.e2e.example` предназначены только для изолированного тестового контейнера.

После запуска стек автоматически удаляется вместе с тестовым volume. Для отладки можно оставить его работающим:

```bash
E2E_KEEP_RUNNING=true npm run test:e2e:auth
```

## Артефакты

```text
artifacts/e2e/playwright-report/
artifacts/e2e/test-results/
artifacts/e2e/compose.log
```

При ошибке сохраняются HTML-отчёт, screenshot, video и trace Playwright, а также логи контейнеров.

## GitHub Actions

Workflow `.github/workflows/e2e-auth.yml` выполняет тот же сценарий на pull request при изменении локальной аутентификации или E2E-инфраструктуры. Артефакты сохраняются на 14 дней.
